# Student Management System

A full-stack Student Management System built with PHP, Laravel, TypeScript, HTML, CSS and MySQL.

This project is being developed incrementally as a learning and portfolio project, starting with basic student registration and CRUD operations and gradually growing into a secure, maintainable academic management application.

## Project Objective

The main objective is to design and develop a student management application while learning:

- Full-stack web development
- PHP and Laravel backend development
- Frontend development with HTML, CSS and TypeScript
- Relational database design with MySQL
- Git and GitHub workflows
- Software architecture and clean code practices
- Application security and automated testing
- CI/CD and deployment

## Technology Stack

| Technology | Purpose |
|---|---|

| TypeScript | Frontend programming |

## Planned Features

### Phase 1 — Minimum Viable Product

- Student registration
- View student records
- View individual student profiles
- Edit student details
- Delete student records
- Search and filter students
- Pagination

### Phase 2 — Authentication and Authorization

- User registration and login
- Secure logout
- Role-based access control
- Administrator and teacher accounts

### Phase 3 — Academic Management

- Class management
- Subject management
- Teacher management
- Student enrollment
- Attendance management
- Examination and grade management

### Phase 4 — Advanced Features

- Dashboard and statistics
- Reports
- CSV import and export
- Audit logs
- Notifications
- Advanced search and filtering

### Phase 5 — Quality and Deployment

- Automated testing
- Application security improvements
- GitHub Actions
- CI/CD workflows
- Production deployment
- Database backup and recovery

## Development Approach

The application will be developed step by step.

Each feature will be implemented, tested, documented and committed separately using Git.

Feature branches and pull requests will be used to practise a professional GitHub development workflow.

## Project Status

**Current status:** Initial repository setup.

Features will be added progressively as development continues.

## Privacy and Security

Only synthetic student information will be used for development and demonstrations. Real student information, credentials, API keys and environment secrets will not be committed to this public repository.
